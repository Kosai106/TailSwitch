# Brand asset

`tailscale.svg` is the Tailscale logo supplied for use as TailSwitch's application and tray icon. Its canvas was cropped to the artwork bounds with a small margin; the geometry and opacity pattern are unchanged.

Tailscale and its logo are trademarks of Tailscale Inc. The logo is used only to identify interoperability with the installed Tailscale client. It is not covered by TailSwitch's MIT license, and its use does not imply affiliation or endorsement. Tailscale's community-project guidance asks that the mark not be used in a way that suggests an official affiliation, which TailSwitch's name, About dialog, and README avoid. At runtime the tray tints the mark to the desktop's foreground colour for legibility; the shipped `tailswitch.svg` launcher icon is the unmodified artwork. If Tailscale Inc. objects to this use, the icon will be replaced.
